# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to Lorde Studios through the GitHub security reporting flow or the verified organization support contact. Do not include credentials, pairing codes or working exploit details in public issues.

## Scope

This distribution repository contains documentation and release artifacts only. Proprietary Browser-use implementation source is maintained separately.

## Runtime safety

Browser-use controls visible browser tabs and, in AGI mode, native computer surfaces. Use explicit pairing, tab binding and approval controls. Do not automate sensitive accounts or irreversible actions without supervision.
