# Support

For release questions and verified product support, use the Lorde Studios organization and the Browser-use GitHub repository:

- https://github.com/LordeStudios
- https://github.com/LordeStudios/Browser-use
- https://studios.lordemaximus.com

When reporting a problem, include the Browser-use version, Windows version, installation type, the affected MCP/provider surface and a sanitized description of the behavior. Never include API keys, pairing codes or private page content.
